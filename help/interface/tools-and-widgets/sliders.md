# Curseurs

![](../../assets/sliders-basic.gif)

Il existe une option permettant d’animer un ou plusieurs curseurs. Appuyez sur **Ctrl** lorsque vous placez le curseur, une icône de **lecture** apparaît pour lancer l&#39;animation.

Vous pouvez mettre l&#39;animation en pause en appuyant sur **Ctrl** lorsque vous survolez un curseur animé, une icône de **pause** apparaît pour arrêter l&#39;animation de ce curseur.

Si vous souhaitez suspendre tous les curseurs, appuyez sur **P**. Pour relancer, appuyez à nouveau sur **P**.
