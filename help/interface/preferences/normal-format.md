# Format normal

Les mappages normaux sont traités à l&#39;aide du format <b>DirectX</b>. Conservez un workflow OpenGL<b></b> pour importer et exporter le format OpenGL en modifiant les préférences de format normal.

*Par défaut : DirectX*

La préférence de format normal a un impact sur :

* Calque d’importation d’image
* Exporter

## Calque d’importation d’image

Lors de l’importation d’une texture normale, le format normal est défini sur le format sélectionné dans Préférences.

### Exporter

#### SBSAR et SBS

Le format normal est un paramètre exposé. Ce paramètre peut être modifié par l’application hôte pour générer la normale au format dont elle a besoin.

#### Formats d’image

La normale est exportée dans le format sélectionné dans Préférences.
