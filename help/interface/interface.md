# Interface

L’espace de travail de Sampler se compose des fenêtres 2D et 3D, des barres latérales gauche et droite et d’un ensemble de panneaux. Chaque panneau étant dédié à un objectif spécifique, différents panneaux sont utiles pendant différentes parties du processus créatif.

## Personnalisation de l’espace de travail

L’espace de travail de Sampler est entièrement personnalisable, vous permettant ainsi de trouver la disposition qui vous convient le mieux. Si vous souhaitez rétablir la disposition par défaut des panneaux, utilisez **Fenêtre > Rétablir la disposition par défaut**.

## Réorganisation des panneaux

Cliquez et faites glisser le titre d’un panneau pour commencer à le déplacer.

Vous pouvez ancrer un panneau sur les bords de la fenêtre d’affichage ou d’autres panneaux : faites glisser le panneau sur le bord où vous souhaitez l’ancrer pour faire apparaître un repère de surbrillance bleu. Lorsque la ligne apparaît, déposez le panneau pour l’ancrer.

## Ouverture et fermeture de panneaux

Utilisez la croix (X) en haut à droite d’un panneau pour le fermer. Les panneaux fermés sont stockés dans les barres latérales.

Pour rouvrir un panneau, cliquez sur l’icône correspondante dans la barre latérale gauche ou droite. Le panneau s’ouvre temporairement. Faites glisser le panneau vers l’extérieur pour qu’il reste ouvert en permanence.

## Menus de l’application

La **barre de menus de l&#39;application** affiche le nom du projet actuel. Il contient également les menus **Fichier**, **Modifier**, **Fenêtre**, **Aide** et **Licence**.

Utilisez le menu <b>Fichier</b> pour créer un projet, ouvrir un projet existant ou enregistrer ou exporter votre projet actuel.

Utilisez le menu <b>Modifier</b> pour annuler et rétablir des actions ou ouvrir les [Préférences](../interface/preferences/preferences.md).

Utilisez le menu <b>Fenêtre</b> pour réinitialiser la disposition par défaut de votre espace de travail.

Utilisez le menu <b>Aide</b>pour en savoir plus sur Sampler ou découvrir comment résoudre les problèmes.

| Élément du menu Aide | Description |
| --- | --- |

| Documentation | Reportez-vous à la documentation. La documentation fournit des informations sur tous les aspects de l’utilisation de Sampler. |
| Documentation de l’API Python | Découvrez comment utiliser l’API Python Sampler pour automatiser les tâches. |
| Raccourcis clavier | Consultez la liste complète des raccourcis clavier. L’utilisation de raccourcis peut vous aider à travailler plus rapidement que si vous utilisiez votre curseur seul. |
| Bienvenue | Ouvrez la <b>fenêtre de bienvenue</b> pour en savoir plus sur les possibilités de Sampler. |
| Nouveautés | Ouvrez la <b>Fenêtre Nouveautés</b> pour voir les modifications apportées à la dernière version de Sampler. |
| Notes de mise à jour | Découvrez les modifications apportées aux versions récentes de Sampler. |
| Forum | Ouvrez les forums pour participer à la conversation avec d’autres membres de la communauté Substance 3D Sampler, ou envoyez vos propres publications et suggestions. |
