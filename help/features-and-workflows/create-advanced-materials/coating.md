# Utilisation des couches de revêtement

Comme son nom l&#39;indique, les couches de revêtement vous permettent d&#39;ajouter un revêtement à votre matériau. Les revêtements peuvent avoir leur propre valeur de rugosité, qui peut affecter la rugosité de base du matériau et aider à créer des effets tels qu&#39;une surface vernie ou polie. Regardez la vidéo ci-dessous pour apprendre à utiliser le canal de revêtement dans Sampler afin de créer un parquet verni à partir de zéro.
