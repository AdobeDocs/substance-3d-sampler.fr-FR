# Version 2020.1 (2.1)

**Substance Alchemist 2020.1 « Tiramisu »** vous permet d’exporter vos matières directement emballées pour les moteurs de rendu et de jeu. Par défaut, 15 paramètres prédéfinis d’exportation sont disponibles, tels que Unity HDRP, Unreal Engine 4, Blender, Vray-Next, etc.

Il comporte un nouveau fichier de configuration et des commandes pour le vérificateur de mise à jour.

Date de publication : *12 mars 2020*

## Principales fonctionnalités

### Fenêtre Nouvel exportateur

![](../../assets/header-exporter.png)

La fenêtre d’exportation a été remaniée afin d’introduire une nouvelle interface dotée de plusieurs nouvelles fonctionnalités :

* **Utilisez les paramètres prédéfinis d&#39;exportation pour compresser les textures d&#39;un moteur de rendu ou de jeu spécifique**. Il est désormais possible de choisir, lors du processus d&#39;exportation, une configuration parmi une liste de paramètres prédéfinis d&#39;exportation qui convertissent, compressent et nomment les textures pour une application tierce spécifique. Le résultat de cette conversion est affiché dans la liste des canaux à droite de l’interface.\
  Le nouvel exportateur inclut les paramètres prédéfinis suivants par défaut :

  * Unreal Engine 4
  * Unity Standard
  * Unity HDRP
  * Cycles mélangeurs/Eve
  * Arnold 5
  * Rendu Corona
  * Enscape
  * Keyshot 9
  * Redshift
  * Vray Next
  * Lens Studio
  * Spark AR Studio
  * SPECULAR/brillance PBR à partir de la rugosité métallique PBR

  ![](../../assets/exporter-preset-list.png)
* **Créez un sous-dossier avec le nom du matériau**\
  Lorsque vous exportez plusieurs matériaux vers un emplacement commun, il est désormais possible de créer un sous-dossier
* **Les paramètres d&#39;exportation sont enregistrés et restaurés lors de la prochaine exportation**\
  Pour plus de facilité, la réouverture de la fenêtre d’exportation réutilisera également les paramètres d’exportation précédemment utilisés. Faciliter et accélérer la réexportation d’un matériau.
* **Créer, importer et gérer des paramètres prédéfinis d&#39;exportation personnalisés**\
  Il est également possible de créer des paramètres prédéfinis d’exportation personnalisés. Pour savoir comment les créer et les gérer, consultez les pages de documentation suivantes :

  * [Gestion des paramètres prédéfinis personnalisés](https://helpx.adobe.com/fr/substance-3d/unlisted/documentation/sadoc/creating-and-importing-custom-presets-188976295.html)
  * [Gestion des paramètres prédéfinis](../../getting-started/export/managing-presets.md)

### Configuration de l’application

![](../../assets/header-config.jpg)

(Photo de [Fabian Grohs](https://unsplash.com/@grohsfabian?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText) sur [Unsplash](https://unsplash.com/?utm_source=unsplash&utm_medium=referral&utm_content=creditCopyText))

Il est maintenant possible de configurer la Substance Alchemist avec un fichier de configuration. Cela facilite la configuration de l’application sur tous les ordinateurs, comme dans un studio par exemple. Les fichiers de configuration définissent les ressources par défaut et la liste des dossiers liés.

Pour en savoir plus sur la création et l&#39;utilisation d&#39;un fichier de configuration, consultez la [page de documentation](https://helpx.adobe.com/fr/substance-3d/unlisted/documentation/sadoc/resources-configuration-file-188976187.html) dédiée.

### Améliorations diverses

![](../../assets/header-checker.png)

Cette version apporte quelques améliorations aux workflows :

* **Focus de la vue 2D**\
  Il est désormais possible d’utiliser le raccourci « F » pour réinitialiser et centrer la vue 2D, comme pour la vue 3D.
* **Rouvrir le dernier projet**\
  Pour faciliter et accélérer la création de contenu, l’application rouvre désormais le dernier projet utilisé. La fonction Créer un laboratoire est désormais également le mode par défaut lors de l’ouverture de l’application.
* **Configuration du vérificateur de mise à jour**\
  Définissez si vous souhaitez être averti si une nouvelle version est disponible. Pour plus d&#39;informations, consultez la [page de documentation](../../technical-support/configuration/update-checker.md) dédiée.

### Nouveau contenu

![](../../assets/header-content.jpg)

Nous avons amélioré certains filtres et mis à jour le contenu de démarrage :

* **Nouvelles matières de base**\
  Nous avons remplacé quelques matériaux existants par de nouveaux, voici la liste des nouveaux matériaux :
  * Microfibre D&#39;Alcantara
  * Sol en moquette
  * Cliff Rock
  * Cuivre
  * Dirt fissuré
  * Grossier
  * Terracota
  * Tissu de laine
  * Tissu
* **Contrôle métallique avec le filtre Matériau Bitmap 2**\
  Le filtre Matériau Bitmap 2 a été mis à jour pour offrir plus de contrôle sur le canal métallique. Il est désormais possible d’utiliser une entrée bitmap personnalisée pour celle-ci ou de définir une couleur uniforme.
* **Amélioration du filtre de réglage**\
  Le filtre Réglage peut désormais fonctionner avec un projet défini pour utiliser le flux de travaux PBR Specular/Lustre.
* **Nouveaux paramètres d&#39;Atlas scatter**\
  Nous avons ajouté quelques nouveaux paramètres pour offrir un meilleur contrôle sur la façon dont les éléments se fondent dans la texture height du matériau ci-dessous.
