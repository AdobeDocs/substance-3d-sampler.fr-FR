# 0.5.0

Date de publication : **2019/02/28**

Ajouté :

* [Pile de calques] Réorganisation des calques
* [Pile de calques] Supprimer un calque masqué
* [Pile de calques] Importez un matériau directement à la position de votre choix
* [Pile de calques] Entrée de matière comme nouveau type de paramètre de filtre
* [Performance] Le budget de Substance Engine est dynamique pour de meilleures performances
* [Performances] Meilleures performances d’OpenGL, en particulier sur MacOS
* [Données] Mise à niveau plus rapide des données après la publication d’une nouvelle version
* [Content] AI Delighter disponible sous Windows 7 et Windows 8
* [Contenu] AI Delighter disponible sur le GPU RTX

Fixe :

* Correction des blocages possibles lors de la fermeture de l’application
* La fenêtre contextuelle Exporter s’ouvre plus rapidement lors de l’exportation de grandes collections

Problèmes connus :

* L’utilisation de plusieurs charmants dans un même matériau n’est pas recommandée
* Delighter se bloque avec les anciens pilotes NVIDIA (moins de 400.x)
* Le bouton d’activation/désactivation de la visibilité rapide d’une scène Delighter affecte les performances
* Blocage lors du chargement de votre propre environnement
