# 0.5.3

Date de publication : **2019/03/19**

Ajouté :

* Recherche par nom de matière dans le panneau Ressources
* [UI] Nouvelle interface utilisateur de l’outil Cloner avec visualisation de l’épaisseur du pinceau
* [UI] Sélection et suppression d’étapes masquées
* [UI] Nouvelle interface utilisateur de champ de texte
* [Help] Accéder aux sites web des académies de Substance Source, Substance share et Substance
* [Contenu] Nouveaux matériaux par défaut avec générateurs et atlas
* [Contenu] Mise à jour du bitmap vers le matériau
* Mise à jour du Dirt [Content]
* Mise à jour de la Rouille [Content]
* [Contenu] Nouveau filtre d’estampage
* [Contenu] Nouveau filtre Broderie
* [Contenu] Nouveau Filtre Érosion
* [Contenu] Nouveau Gravel Generator
* [Contenu] Nouveau filtre Peinture
* [Contenu] Nouveau filtre Motif de parquet
* [Contenu] Nouveau filtre Motif de chaussée
* [Contenu] Nouveau filtre Perforation
* [Contenu] Nouveau filtre Éclaboussure
* [Contenu] Nouveau Filtre d&#39;usure textile
* [Contenu] Nouveau filtre Transformation

Fixe :

* [Fenêtre d’affichage] Maillage sphère avec mosaïque x2 sur X
* [Fenêtre] Blocage lors du chargement de votre propre environnement
* [Fenêtre d’affichage] Les mappages d’environnement utilisent désormais également la valeur d’exposition
* [Fenêtre d’affichage] Le raccourci F ne réinitialise pas l’angle de caméra
* [Export] L&#39;exportation SBS fonctionne avec la dernière Substance Designer 2018.3.3
* [Export] L&#39;exportation SBSAR respecte les mêmes directives que les matériaux de Substance Source
* [UI] Vous pouvez faire glisser les barres de défilement.
* Les caractères spéciaux sont pris en charge dans les chemins de dossier et de fichier
* La vignette est régénérée lorsque vous enregistrez votre matière

Problèmes connus :

* L’utilisation de plusieurs charmants dans un même matériau n’est pas recommandée
* Delighter se bloque avec les anciens pilotes NVIDIA (moins de 400.x)
* Le bouton d’activation/désactivation de la visibilité rapide d’une scène Delighter affecte les performances
* L’importation d’environnement personnalisée peut devenir noire
* Les images Tif ne s’affichent pas dans le panneau Propriétés du calque d’importation d’image
* Les virgules ou les points peuvent être ignorés lors de la saisie d’une valeur spécifique dans un curseur
* La collection par défaut dans laquelle enregistrer peut être vide
