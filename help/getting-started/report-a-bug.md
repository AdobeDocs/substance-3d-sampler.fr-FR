# Signaler un bogue

Vous pouvez signaler les bogues à partir de Sampler.

Ouvrez le menu <b>Aide</b>, puis sélectionnez <b>Signaler un bogue</b>g :

![](../assets/Bug-report-howto.png.img.png){width="700px"}

Remplissez le formulaire suivant :

![](../assets/Bug-report-window.png.img.png){width="400px"}

Appuyez ensuite sur Envoyer. Les informations que vous avez saisies seront partagées directement avec l’équipe de développement Sampler.
