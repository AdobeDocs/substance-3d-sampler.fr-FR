# Gestion des paramètres prédéfinis

Les paramètres prédéfinis vous permettent de configurer rapidement votre fichier exporté pour une application donnée. Vous pouvez également créer des paramètres prédéfinis personnalisés selon vos besoins si vous utilisez un pipeline non couvert par les paramètres prédéfinis par défaut.

## Utiliser les paramètres prédéfinis

Les paramètres prédéfinis sont uniquement disponibles lors de l’exportation vers un fichier image. Lors de l’exportation au format SBS ou SBSAR, les paramètres prédéfinis ne sont pas nécessaires.

Pour accéder aux paramètres prédéfinis :

1. Ouvrez la fenêtre <b>Exporter</b> :
   1. Utilisez le <b>panneau Exporter</b> dans la <b>barre de droite</b>.
   1. Utiliser Fichier <b> > Exporter en tant que...</b>
   1. Utiliser le raccourci <b>Ctrl + E.</b>
1. Sur le côté gauche de la fenêtre <b>Exporter </b>, sélectionnez <b>Paramètres de matière</b>.
1. Sélectionnez un format d’image (EXR, JPEG, PNG, TARGA, TIFF)
1. La liste des paramètres prédéfinis s’affiche.

![](../../assets/Managing-presets-Dropdown.png.img.png){width="400px"}

Utilisez la liste déroulante Paramètres prédéfinis pour sélectionner un paramètre prédéfini, ou utilisez le bouton <b>Gérer les paramètres prédéfinis </b> en regard de la liste déroulante pour gérer vos paramètres prédéfinis.

## Gérer les paramètres prédéfinis

Utilisez la liste déroulante Paramètres prédéfinis pour sélectionner un paramètre prédéfini, ou utilisez le bouton <b>Gérer les paramètres prédéfinis </b> en regard de la liste déroulante pour gérer vos paramètres prédéfinis.

## Paramètres prédéfinis par défaut

![](../../assets/Managing-presets-Window.png.img.png){width="400px"}

Pour tous les paramètres prédéfinis par défaut, vous pouvez les activer/désactiver. Si un paramètre prédéfini par défaut est désactivé, il ne sera pas visible dans la liste déroulante Paramètre prédéfini.

Par défaut, tous les paramètres prédéfinis sont activés.

## Paramètres prédéfinis personnalisés

Vous pouvez activer/désactiver les paramètres prédéfinis personnalisés. Si un paramètre prédéfini personnalisé est désactivé, il ne sera pas visible dans la liste déroulante Paramètre prédéfini.

Vous pouvez également :

* <b>Renommer</b> : modifiez le nom du paramètre prédéfini dans l&#39;interface.
* <b>Remplacer</b> : remplacez le fichier de votre paramètre prédéfini par une nouvelle version.
* <b>Supprimer</b> : supprimez le paramètre prédéfini.
