# Gestion des projets

Dans Substance 3D Sampler, vous pouvez utiliser les collections pour gérer tous vos actifs et matières. Les projets sont un bon moyen d’organiser vos matériaux. Un projet peut être exporté ou importé pour être facilement partagé entre plusieurs ordinateurs.

## Créer un nouveau projet

Pour créer un nouveau projet, sélectionnez <b>Créer</b> dans l&#39;écran <b>Accueil</b> ou <b>Fichier > Nouveau projet</b>. La création d’un projet affiche la boîte de dialogue Démarrage rapide, dans laquelle vous pouvez sélectionner une action rapide ou importer une image ou un fichier de Substance pour démarrer votre projet.

![](../assets/6.0_HomeScreenFocus.png)

Vous pouvez également utiliser le bouton <b>Démarrage rapide</b> pour accéder directement à un projet vide. Vous pouvez toujours importer manuellement des actifs et du contenu selon vos besoins.

Après avoir cliqué sur le bouton « Créer », le projet s’ouvre automatiquement et porte le nom « *Projet sans titre\** » jusqu’à ce que vous l’enregistriez. Vous pouvez ajouter des ressources à votre projet avec le <b>bouton Nouvelle ressource </b> en surbrillance dans le <b>panneau Projet</b>.

![](../assets/Project_CreateNew_1.png){width="600px"}

## Enregistrement d’un projet

Pour enregistrer un projet, utilisez l&#39;action de menu <b>Fichier > Enregistrer </b> ou <b>Enregistrer sous</b>. Une boîte de dialogue s’ouvre alors pour vous permettre de choisir le nom à utiliser et l’emplacement d’enregistrement des fichiers de projet.

Vous pouvez également utiliser le raccourci <b>Ctrl + S</b> pour <b>Enregistrer</b> ou <b>Ctrl + Maj + S</b> pour <b>Enregistrer sous</b>.

Les projets enregistrés apparaissent sous la forme d&#39;un fichier nommé <b>YourProject.ssa</b>. SSA est un format de fichier d’échantillonnage qui stocke des informations sur votre projet et ses éventuelles dépendances.

## Ouverture d’un projet existant

Les projets peuvent être ouverts de plusieurs façons :

* Dans l&#39;<b>écran d&#39;accueil</b> : utilisez la liste des projets récents pour ouvrir rapidement un projet en double-cliquant dessus.
* Dans l&#39;<b>écran d&#39;accueil</b> : cliquez sur <b>Ouvrir</b> pour ouvrir un navigateur de fichiers dans lequel vous pouvez choisir le fichier que vous souhaitez ouvrir.
* Via le menu **Fichier > Ouvrir un projet**.
