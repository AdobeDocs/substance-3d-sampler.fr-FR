# Gestion des projets

Dans Substance 3D Sampler, vous pouvez utiliser les collections pour gérer tous vos actifs et matériaux. Les projets sont un bon moyen d’organiser vos matériaux. Un projet peut être exporté ou importé pour être facilement partagé entre plusieurs ordinateurs.

## Créer un nouveau projet

Pour créer un projet, sélectionnez **Créer** dans l&#39;écran **Accueil** ou **Fichier > Nouveau projet**. La création d&#39;un nouveau projet ouvre la boîte de dialogue Démarrage rapide, dans laquelle vous pouvez sélectionner une [action rapide](../features-and-workflows/quick-actions.md) ou importer une image ou un fichier de Substance pour démarrer votre projet.

>[!TIP]
>
> Si vous débutez avec Sampler, les [actions rapides](../features-and-workflows/quick-actions.md) peuvent vous aider à démarrer rapidement en vous renseignant sur ce que Sampler peut vous aider à réaliser.

![](../assets/6.0_HomeScreenFocus.png)

Vous pouvez également utiliser le bouton **Démarrage rapide** pour accéder directement à un projet vide. Vous pouvez toujours importer manuellement des actifs et du contenu selon vos besoins.

Après avoir cliqué sur le bouton « Créer », le projet s’ouvre automatiquement et porte le nom « *Projet sans titre\** » jusqu’à ce que vous l’enregistriez. Vous pouvez ajouter des ressources à votre projet avec le **bouton Nouvelle ressource** en surbrillance dans le **panneau Projet**.

![](../assets/Project_CreateNew_1.png){width="600px"}

## Enregistrement d’un projet

Pour enregistrer un projet, utilisez l&#39;action de menu **Fichier > Enregistrer** ou **Enregistrer sous**. Une boîte de dialogue s’ouvre alors pour vous permettre de choisir le nom à utiliser et l’emplacement d’enregistrement des fichiers de projet.

Vous pouvez également utiliser raccourci **Ctrl + S** pour **enregistrer** ou **Ctrl + Maj + S** pour **enregistrer sous**.

Les projets enregistrés apparaissent sous la forme d&#39;un fichier nommé **YourProject.ssa**. SSA est un format de fichier d’échantillonnage qui stocke des informations sur votre projet et ses éventuelles dépendances.

## Ouverture d’un projet existant

Les projets peuvent être ouverts de plusieurs façons :

* Dans l&#39;**écran d&#39;accueil** : utilisez la liste des projets récents pour ouvrir rapidement un projet en double-cliquant dessus.
* Dans l&#39;**écran d&#39;accueil** : cliquez sur **Ouvrir** pour ouvrir un navigateur de fichiers dans lequel vous pouvez choisir le fichier que vous souhaitez ouvrir.
* Via le menu **Fichier > Ouvrir un projet**.
