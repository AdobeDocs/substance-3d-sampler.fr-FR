# Envoyer vers n’importe quelle application

À partir de la version 4.5 de Sampler, vous pouvez désormais envoyer vos ressources de Sampler directement vers n’importe quelle application où le connecteur a été implémenté.\
Cela permet d’envoyer des ressources de Sampler vers des applications tierces en un clic, afin d’éviter d’avoir à passer par le processus manuel d’exportation et d’importation et de gagner du temps.

Aujourd’hui, le Send-to est disponible dans Blender, Unreal Engine, Unity, 3ds Max et Maya via les plug-ins de Substance.

## Versions d’application prises en charge

Pour pouvoir utiliser l’outil Envoyer vers, il est nécessaire d’avoir la bonne version de Sampler, de l’application tierce et des plug-ins.

Voici les versions minimales dont vous avez besoin pour pouvoir utiliser l’option Envoyer à :

* <b>Plug-In Unreal Engine</b>
  * Tout ce qui suit UE5.4 est entièrement pris en charge.
  * *Publié sur la marketplace UE*

* <b>Plug-in Maya v3.0.0+</b>
  * Pris en charge dans Maya 2025, 2024, 2023 et 2022
  * *Disponible gratuitement depuis Maya 2025, pour les versions précédentes, le plug-in doit être téléchargé à partir du [site web](https://www.adobe.com/fr/products/substance3d/plugins/substance-in-maya.html "Page web Substance en maya")*

* <b>Plug-in 3ds Max v3.0.0+</b>
  * Pris en charge dans 3ds Max 2025, 2024, 2023 et 2022
  * *Disponible prêt à l&#39;emploi depuis 3ds Max 2025, pour les versions précédentes, le plug-in doit être téléchargé à partir du [site web](https://www.adobe.com/fr/products/substance3d/plugins/substance-in-3ds-max.html "Substance dans la page web 3ds Max")*

* <b>Plug-in Unity v3.11+</b>
  * Versions Unity 2022, 2021 ou 2020
  * *Le plug-in doit être téléchargé à partir de l&#39;Asset Store*

* <b>Plug-in Blender v2.1+</b>
  * Blender versions 3.0 et ultérieures
  * *Le plug-in peut être téléchargé sur le [site web](https://www.adobe.com/fr/products/substance3d/plugins/substance-in-blender.html "Substance dans la page web de Blender")*
