# Variables d’environnement

Cette page répertorie les variables d&#39;environnement qui peuvent être utilisées pour remplacer le comportement par défaut de l&#39;application.

| Variable | Description |
| --- | --- |
| **SUBSTANCE\_SAMPLER\_LICENSE** | Valeur : chemin d’accès au fichier license.keyRemplacez l’emplacement à partir duquel l’application charge le fichier de licence.  **Remarque :** les versions antérieures à la version 3.0 utilisent ce nom de variable à la place :**SUBSTANCE\_ALCHEMIST\_LICENSE** |
