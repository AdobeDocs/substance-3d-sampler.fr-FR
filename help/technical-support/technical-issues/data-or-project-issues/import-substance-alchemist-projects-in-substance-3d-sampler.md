# Importation de projets Substance Alchemist dans Substance 3D Sampler

À partir de la version 3.0.0, les projets de Substance Alchemist précédents ne sont pas automatiquement disponibles. Cette page explique comment les récupérer.

## 1 - Substance Alchemist de lancement

1. Ouvrez le projet de votre choix dans Alchemist
1. Cliquez sur **Fichier** > **Exporter le projet...**
1. Choisissez l&#39;emplacement du projet et cliquez sur **OK**

Après cette action, un fichier **.alch** avec un dossier **dépendances** sera disponible.

### 2 - Lancement de Substance 3D Sampler

1. Dans l&#39;**écran d&#39;accueil**, cliquez sur **Ouvrir**
1. Accédez au dossier où se trouve le fichier **.alch**.
1. Ouvrez le fichier **.alch** (assurez-vous que le dossier **dépendances** est toujours à côté du fichier .alch).

Tous vos matériaux seront répertoriés dans le panneau Projet sous la section Matériaux.
