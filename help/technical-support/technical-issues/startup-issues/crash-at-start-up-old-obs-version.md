# Blocage au démarrage - Ancienne version d’OBS

L&#39;application peut se bloquer au démarrage en raison d&#39;une ancienne version de [OBS](https://obsproject.com/fr) installée.

Pour résoudre ce problème, mettez à jour [OBS version](https://obsproject.com/fr/download) ou désinstallez-le.
