# Artefacts visuels entre l’image et le matériau

Les résultats de l&#39;<b>transformation de l&#39;image en matériau (optimisée par l&#39;IA)</b> peuvent parfois être modifiés (principalement avec des couleurs incorrectes).

Activez ou désactivez les *réseaux neuronaux à accélération GPU* dans la section <b> Machine learning</b> des Préférences de Substance 3D Sampler pour résoudre le problème.
