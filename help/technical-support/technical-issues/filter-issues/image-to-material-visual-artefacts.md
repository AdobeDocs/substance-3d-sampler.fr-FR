# Artefacts visuels de l’image au Matériau

Les résultats de <b>l&#39;image au Matériau (optimisé par l&#39;IA)</b> peuvent parfois être modifiés (principalement avec des couleurs incorrectes).

Activez ou désactivez les *réseaux neuronaux à accélération GPU* dans la section <b> Machine learning</b> des Préférences de Substance 3D Sampler pour résoudre le problème.
