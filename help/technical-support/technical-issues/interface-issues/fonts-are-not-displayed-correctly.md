# Les polices ne s’affichent pas correctement

Si vous utilisez Windows 10 Entreprise et la fonctionnalité [Bloquer les polices non approuvées](https://docs.microsoft.com/en-us/windows/security/threat-protection/block-untrusted-fonts-in-enterprise), vous pouvez suivre ce [tutoriel](https://www.tenforums.com/tutorials/139148-exclude-specific-apps-untrusted-font-blocking-windows-10-a.html) pour exclure Sampler de la liste des applications non approuvées pour le blocage des polices.
