# Blocage lors de l’exportation d’un matériau

Un blocage lors de l’exportation peut se produire lors de l’exportation d’une matière créée dans Sampler. Ce blocage est généralement dû à un manque de VRAM disponible sur le GPU lors du démarrage du processus d’exportation (en particulier avec les matériaux utilisant le filtre Delighter).

La réduction de la résolution d’exportation et la fermeture de toutes les autres applications peuvent aider à libérer de la mémoire pour permettre la fin de l’exportation.
