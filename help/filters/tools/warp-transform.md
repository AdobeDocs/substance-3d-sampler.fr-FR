## Paramètres

**Paramètres de base**

* **Grille** :\
  Ajustez le nombre de divisions dans la grille. L’augmentation du nombre de divisions vous permettra de mieux contrôler la déformation.
* **Afficher la grille** : activer/désactiver\
  Lorsque cette option est activée, une grille s’affiche sur le matériau pour faciliter la visualisation des effets du filtre
* **Échantillonnage haute qualité** : activer/désactiver\
  Activez cette option pour améliorer la qualité de l’échantillonnage et obtenir de meilleurs résultats.

## Guide d’utilisation

Le **filtre Transformation de déformation** vous permet de déformer manuellement votre matière à l&#39;aide de poignées dans la **vue 2D**. Pour utiliser le **filtre Transformation de déformation** :

1. Ajoutez le **filtre Transformation de déformation** en haut de la pile de calques
1. Ajuster le nombre de poignées avec **Paramètres de base > Grille**
1. Faites glisser les poignées pour commencer à déformer la matière
