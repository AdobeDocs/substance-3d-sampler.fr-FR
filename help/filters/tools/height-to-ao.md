## Description

Générer une carte d&#39;Occlusion ambiante à partir des données d&#39;height et normales.

Voir les résultats du **Height du filtre AO** dans les images ci-dessous.

![](../../assets/3d-2d-filters-cropped-0025-height-to-ao-in.jpg)

Dans l&#39;image ci-dessus, la **vue 2D** affiche la carte d&#39;height. Le matériau n’inclut aucune information d’Occlusion ambiante dans cette image.

![](../../assets/3d-2d-filters-cropped-0024-height-to-ao-out.jpg)

Dans cette image, la carte d&#39;Occlusion ambiante a été créée par le filtre **Height à AO** et est visible dans la **vue 2D**. L&#39;Occlusion ambiante est généralement un effet subtil. Il n&#39;est donc pas très facile de la voir dans ce matériau. Essayez d&#39;utiliser le **filtre Height à l&#39;AO** sur vos matériaux pour augmenter l&#39;intensité de l&#39;AO et vous familiariser avec l&#39;Occlusion ambiante.

## Paramètres

**Paramètres de base**

* **Mode** :\
  Indiquez si les données doivent être générées à partir de la couche height, de la couche normale ou des deux couches ensemble.
* **Occlusion ambiante - Intensité** : 0-1\
  Régler l’intensité des données d’IA générées
* **Occlusion ambiante - Répartition** : 0-1\
  Réglage du rayon des données d’IA générées
