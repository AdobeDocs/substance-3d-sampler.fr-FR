## Description

Le filtre Netteté vous permet d’accentuer les détails d’une couche spécifique.

Remarque : bien que le filtre Netteté soit idéal pour ajouter rapidement des détails, il peut être facile d’en abuser et de faire apparaître une couche bruyante, ce qui occulte les détails. Essayez de trouver un bon équilibre.

## Paramètres

**Paramètres prédéfinis**

Utilisez les paramètres prédéfinis pour modifier rapidement les paramètres et voir les différents styles de parquet.

**Paramètres de base**

* **Sélection de canal** :\
  Sélectionnez la couche à laquelle appliquer la netteté.
* **Netteté** : 0-3\
  Réglez l’intensité de l’effet Netteté.

**Masquer**

* **Utiliser un masque personnalisé** : activer/désactiver\
  Activez ou désactivez l’utilisation d’un masque personnalisé. Si cette option est activée, les paramètres suivants apparaissent :
  * **Masque** : image/pinceau\
    Sélectionnez une image à utiliser comme masque ou utilisez le pinceau pour peindre un masque personnalisé directement dans la vue 2D
  * **Masque personnalisé - Flou** : 0-1\
    Flouter le masque
  * **Masque personnalisé - Inverser** : activer/désactiver\
    Inverser le masque
