## Paramètres

<b>Paramètres de base</b>

* <b>Mosaïque d&#39;entrée</b> : basculer\
  Activez ce paramètre pour vous assurer que ce filtre ne casse pas les matériaux de mosaïque.
* <b>Rayon</b> : 0-50\
  Réglez le rayon pour contrôler la taille des plis que le filtre tente de réduire. Un rayon faible lisse les détails les plus fins.
* <b>Détails locaux</b> : 0-1\
  Utilisez une valeur plus élevée pour conserver les détails locaux tout en supprimant les plis.

<b>Normal</b>

* <b>Remplacer les paramètres courants</b> : activer/désactiver\
  Contrôlez les paramètres de cette couche individuellement.

<b>Height</b>

* <b>Remplacer les paramètres courants</b> : activer/désactiver\
  Contrôlez les paramètres de cette couche individuellement.

<b>Masquer</b>

* <b>Masque personnalisé</b> : basculer\
  Activez l’utilisation d’un masque personnalisé pour contrôler l’endroit où les effets de ce filtre apparaissent.
* <b>Masque personnalisé</b> : sélection du pinceau/de l&#39;image\
  Créez ou sélectionnez un masque personnalisé.
* <b>Inversion de masque personnalisée</b> : basculer\
  Inversez le masque.
